# PolyMindAtlass

An interactive, conceptual architecture showcase for multi-model research, evidence quality, authorization, and human review.

This public repository contains the deployable website. System Atlas, Deep Dive, Azure reference architecture, and Pipelines are illustrative views, not live operational telemetry.

## Preview

Run `python3 -m http.server 8769 --bind 127.0.0.1` and open `http://127.0.0.1:8769`.

## Deployment

Deploy with Vercel using the included configuration. No frontend compilation step is required.
